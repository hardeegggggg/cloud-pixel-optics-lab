# 项目实施模板

## 1. 问题定义

研究在公开、虚构的 CMOS 像素结构中，波长、入射角和微透镜偏心如何影响有效响应与邻像素串扰，并验证云端参数扫描的吞吐量、可靠性和成本。

## 2. 假设

- 大角度入射会降低有效响应并增加横向能量偏移。
- 微透镜偏心会造成左右串扰不对称。
- 参数案例相互独立，适合数组任务并行化。
- Spot 可降低总成本，但必须通过幂等写入和 checkpoint 控制中断风险。

## 3. 里程碑

### M1：本地基线

- 生成 1240 个案例。
- 验证响应值范围、法向入射 Fresnel 公式和串扰方向。
- 输出可重复的 CSV。

### M2：云端并行化

- 容器化仿真任务。
- 部署 Batch、S3 和日志基础设施。
- 比较 1、10、100 个并行任务的吞吐量与成本。

### M3：可靠性改进

- 修复 ISSUE-001、002、005、006。
- 注入任务失败和 Spot 中断。
- 证明重试不会重复或覆盖有效结果。

### M4：物理模型升级

- 引入方位角、偏振与材料色散。
- 用公开的 FDTD/RCWA 案例校准代理模型。
- 报告数值误差和适用边界。

## 4. 实验记录字段

- Git commit SHA
- model version
- run ID
- 参数文件哈希
- 容器镜像 digest
- 实例类型、vCPU、内存
- 成功/失败/重试次数
- 总墙钟时间、vCPU 小时和估算成本
- 最大误差、平均误差和异常案例

## 5. 验收标准

- 相同输入与模型版本产生相同结果。
- 越界任务给出清晰错误，不泄漏内部堆栈作为唯一诊断信息。
- 重试不会覆盖其他实验的数据。
- 中断后可恢复，已完成案例不重复计算。
- 物理指标均有单位、范围和参考来源。
- 云资源具有加密、最小权限、成本上限和清理说明。
